## 1. Objectives

The primary goal of this project was to build a fully functional Security Operations Center (SOC) home laboratory capable of collecting, monitoring and investigating security events generated by Windows systems.

At the end of this project I was able to:

1. Build a virtual cybersecurity lab using Oracle VirtualBox.
2. Deploy a preconfigured Wazuh SIEM server.
3. Install Windows 10 as a monitored endpoint.
4. Install Kali Linux as a security testing workstation.
5. Install and configure the Wazuh Agent.
6. Deploy Microsoft Sysmon for enhanced Windows logging.
7. Monitor Windows Event Logs in real time.
8. Generate authentication failure events.
9. Perform basic threat hunting using Wazuh.
10. Investigate security alerts as a Tier 1 SOC Analyst.

## 2. Introduction

Modern organizations rely on hundreds or even thousands of computers, servers and network devices to perform daily business operations. Every action performed on these systems generates digital records known as logs.

Without centralized monitoring, security teams would struggle to detect malicious activity such as unauthorized access, malware infections or insider threats.

A Security Information and Event Management (SIEM) platform collects logs from multiple devices, analyzes them and alerts security analysts whenever suspicious activity is detected.

This project demonstrates how a Security Operations Center can be built using entirely free and open-source technologies. The lab simulates a real enterprise environment where security events are collected from a Windows endpoint, enriched by Microsoft Sysmon, and analyzed through the Wazuh SIEM platform.

Throughout this project, I built the environment from scratch, configured the required components, verified communication between systems and investigated Windows authentication failure events using the Wazuh dashboard.

## 6. Importance to an Organization

Organizations generate thousands of security events every day. Without centralized monitoring, malicious activities can remain undetected for extended periods, increasing the risk of data breaches and operational disruptions.

A SIEM platform such as Wazuh enables security teams to:

* Collect logs from multiple systems into one central location.
* Detect suspicious activities in real time.
* Monitor user authentication attempts.
* Investigate security incidents efficiently.
* Support compliance requirements.
* Reduce the time required to detect and respond to threats.

By implementing endpoint monitoring with Sysmon and centralized log analysis with Wazuh, organizations gain improved visibility into activities occurring across their infrastructure.

## 8. Executive Summary

This project demonstrates the design and implementation of a functional Security Operations Center (SOC) home lab using Oracle VirtualBox, Windows 10, Kali Linux, Wazuh SIEM and Microsoft Sysmon.

The lab simulates a real-world enterprise environment where endpoint logs are collected, analyzed and investigated through a centralized SIEM platform. During the project, I configured virtual machines, deployed the Wazuh agent, enhanced Windows logging with Sysmon, resolved connectivity issues, and verified successful log collection.

To validate the environment, I generated Windows authentication failures and investigated the resulting alerts within the Wazuh dashboard using threat hunting techniques. This project strengthened my practical skills in SIEM administration, endpoint monitoring, log analysis, troubleshooting and incident investigation, closely reflecting the day-to-day responsibilities of a Tier 1 Security Operations Center (SOC) Analyst.
